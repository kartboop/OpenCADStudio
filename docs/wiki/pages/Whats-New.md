# What's New

This local edition is a simplified 2D derivative of Open CAD Studio. It removes 3D authoring, peripheral model formats, plug-ins, node graphs, external automation endpoints, update checks, and promotional/social features.

The focus is engineering drawings: DWG/DXF/DWT, PDF and image workflows, SHX text recognition, 2D drafting, annotation, layers, blocks, references, measurement, layouts, and basic editing.

Historical upstream release notes remain in the source tree's `CHANGELOG.md` and `changelogs/` directory. They describe what those releases contained at the time, not the capabilities of this lightweight edition.
