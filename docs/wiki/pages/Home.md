# Open CAD Studio Help

Open CAD Studio lightweight edition is a local 2D engineering-drawing application for desktop and web. It opens and saves DWG and DXF directly, without a cloud conversion service.

This edition focuses on drawing, annotation, layers, blocks, references, measurement, layouts, PDF/image workflows, and SHX text recognition. It does not include 3D authoring, plug-ins, node graphs, or external automation endpoints.
