# Ribbon Reference

The lightweight ribbon contains the built-in 2D drafting tabs below. **Block Editor** and **Table Cell** also appear in their editing contexts. `CUI` can add a **My Tools** tab with custom panels.

A button with an arrow opens related tools; the last selected item can become the button face.

## Draw

| Panel | Tools |
| --- | --- |
| Draw | Lines, polylines, circles, arcs, rectangles, polygons, ellipses, hatches, points, splines, construction lines, rays, regions, wipeouts, revision clouds, and donuts |
| Modify | Move, copy, stretch, rotate, mirror, scale, trim, extend, fillet, chamfer, arrays, erase, explode, offset, break, join, lengthen, align, draw order, and curve editors |
| Annotation | Text, dimensions, and leaders |
| Layers | Layer list, visibility, freeze, lock, current layer, isolation, walk, and matching tools |
| Block | Block creation and editing, and attribute editing |
| Properties | Match Properties and default colour, linetype, lineweight, and transparency |
| Groups | Group and Ungroup |
| Clipboard | Paste, copy, and cut |
| Measurement | Distance, radius, angle, and area |

## Parametric

| Panel | Tools |
| --- | --- |
| Geometric | Coincident, parallel, tangent, collinear, perpendicular, concentric, horizontal, vertical, symmetric, fixed, and equal constraints |
| Dimensional | Linear, horizontal, vertical, aligned, angular, radius, and diameter constraints |
| Manage | Delete constraints, Parameters Manager, and constraint settings |

## Insert

| Panel | Tools |
| --- | --- |
| Block | Insert, attribute editing, and attribute display |
| Block Definition | Block, Write Block, attribute definition/management, and Block Editor |
| Reference | External references, PDF/image/DWF/DGN underlays, clipping, adjustment, layers, frames, and underlay snapping |
| Import | PDF Import, SVG Import, Recognize SHX Text, recognition settings, and Combine Text |
| Data | Fields, update fields, OLE objects where supported, and hyperlinks |
| Linking & Extraction | Data links and data extraction |
| Content | Content Browser and DesignCenter |

## Layout

While a sheet layout is active, the contextual tab provides viewport creation, Page Setup, and print/publish tools.

For command names and aliases, use the application's autocomplete and the maintained `docs/commands-reference.md` summary.
